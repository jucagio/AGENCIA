## 1. COMPOSICIÓN DE SOLUCIONES

### A. Análisis del Benchmark

#### GTC Corporation
- **Portafolio:** 4 servicios principales
  - Desarrollo de Software
  - Funcional y Aseguramiento (QA especializado)
  - Suministro IT Talento (staff augmentation)
  - Semilleros (capacitación y upskilling)

- **Estrategia de Bundling:**
  - Ofrece desarrollo + QA de forma integrada (no separados)
  - Talento sale de sus propios semilleros (ciclo cerrado)
  - Permite facturación en múltiples líneas al mismo cliente

- **Diferenciador:** Profunda especialización en IBM i/AS400, que es legacy pero hyper-rentable y con clientes de alto valor (instituciones financieras).

#### iData Global
- **Portafolio:** 4 servicios modulares con clara jerarquía
  - Strategy & Consulting (puerta de entrada)
  - Data Delivery (implementación)
  - Data Operations (soporte continuo)
  - Cloud Services Provider (infraestructura)

- **Estrategia de Bundling:**
  - Cliente entra por consultoría → se convierte en proyecto de data
  - Data Delivery necesita Cloud Services (venta cruzada)
  - Data Operations es retención pasiva (MRR predecible)
  - Premios y trust indicators (MS & TD SYNNEX 2024) visible al llegar

- **Diferenciador:** Visión clara de "elevar el activo más importante: los datos". Narrativa unificada. Cada servicio se vende como escalón de maduración del cliente.

#### Arandinni
- **Portafolio:** 5 servicios + sub-servicios (estratificados)
  - Data Analytics (Data Sky, Desarrollo, Consultoría, Soporte)
  - Infrastructure Cloud
  - Apps & Automation (Capacitaciones, Consultoría)
  - Business Devices
  - Project Management (Capacitaciones, Consultoría, Soporte, Implementaciones)

- **Estrategia de Bundling:**
  - Cada servicio tiene **sub-servicios internos**: capacitación, consultoría, soporte, implementación
  - Cliente que compra Data Sky → compra también capacitaciones de su equipo
  - Arandinni "acompaña" todo el ciclo (implementación + capacitación + soporte)
  - Duración de cliente es larga porque está "amarrado" a ellos

- **Diferenciador:** "Resolver tu necesidad de manera inmediata". Énfasis en disponibilidad 24/7, capilaridad nacional (15 años operando). Presencia en "Templo de la Moda", "Banco Unión", "Bata" — clientes corporativos grandes.

## 4. STACK TECNOLÓGICO

### A. Análisis del Benchmark

#### GTC Corporation
- **Stack inferido:** IBM i/AS400 (core), COBOL/RPG (legado), posiblemente APIs modernas
- **Por qué:** Especialización en finanzas legacy requiere expertise profunda
- **Mejorable:** No comunica stack (ventaja competitiva opaca)

#### iData Global
- **Stack inferido:**
  - Data: Databricks/Snowflake, Python, SQL
  - Cloud: AWS/Azure (MS partnership visible)
  - BI: Power BI o Tableau
  - Infraestructura: Kubernetes, CI/CD moderno

- **Por qué:** Data & Cloud requiere ecosistema robusto
- **Mejorable:** Debería comunicar "Databricks Lakehouse" públicamente

#### Arandinni
- **Stack inferido:**
  - MS 365 (Power Apps, Power BI, Project)
  - Cloud: Azure/AWS
  - Automatización: Power Automate
  - Móvil: App Store/Play Store

- **Por qué:** Ecosistema Microsoft es estándar en corporativo colombiano
- **Mejorable:** No diferencia entre soluciones low-code vs custom

### B. Comparación con nuestro stack

**Nuestro stack actual:**
- Backend: Python (FastAPI) ✅
- Frontend: Next.js / React ✅
- Mobile: Flutter ✅
- IA: Claude API, LangChain ✅
- Bases de datos: Supabase, PostgreSQL ✅
- Automatización: n8n, Make ✅
- Orquestación: Paperclip (en roadmap) ⏳

**Fortalezas vs benchmark:**
- Más moderno que GTC (IBM legacy)
- Comparable a iData (aunque ellos tienen cloud enterprise)
- Superior en automatización vs Arandinni (Power Automate es low-code limitado)

**Gaps identificados:**
