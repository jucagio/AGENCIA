# Claude Copywriter — 24+ Patrones de Escritura de Alta Conversión

## Los 24 Patrones Fundamentales

### Patrones de Apertura (capturar atención en los primeros 3 segundos)

**1. El Problema Doloroso**
Abre con el dolor exacto del lector, sin suavizarlo.
```
❌ "¿Quieres mejorar tus ventas?"
✅ "Llevas 3 meses perdiendo deals en la última llamada. El producto es bueno. El precio es justo. Algo en la conversación no está funcionando."
```

**2. La Estadística Impactante**
Un número que reenmarca la realidad del lector.
```
✅ "El 67% de los compradores B2B ya tomaron su decisión antes de hablar con un vendedor. La pregunta es: ¿tomaron la decisión correcta sobre tu empresa?"
```

**3. La Historia Específica**
Protagonista concreto + situación real + resultado verificable.
```
✅ "Marcela tenía una agencia de marketing con 8 clientes. En 90 días, automatizó su onboarding, redujo el tiempo administrativo en 12 horas/semana, y cerró 3 clientes nuevos con el tiempo recuperado."
```

**4. La Pregunta Incómoda**
Fuerza al lector a confrontar algo que ha estado ignorando.
```
✅ "¿Cuánto dinero llevas dejando en la mesa porque tu proceso de ventas depende de que tú estés disponible?"
```

**5. La Declaración Contraintuitiva**
Contradice lo que el lector "sabe" que es verdad.
```
✅ "Las empresas que crecen más rápido en 2026 no están contratando más vendedores. Están automatizando mejor."
```

---

### Patrones de Cuerpo (construir deseo y credibilidad)

**6. Antes/Después/Puente**
Estado actual → estado deseado → cómo llegar.
```
ANTES: "Tu equipo pasa 15 horas/semana en tareas administrativas repetitivas."
DESPUÉS: "Tu equipo se enfoca 100% en lo que genera dinero."
PUENTE: "El sistema de automatización de la Agencia elimina el trabajo repetitivo en 30 días."
```

**7. Características → Beneficios → Significado**
No vendas el drill, vende el hueco. No vendas el hueco, vende la foto en la pared.
```
Característica: "Automatización de onboarding de clientes"
Beneficio: "Cada cliente nuevo tiene una experiencia consistente y profesional"
Significado: "Tu reputación crece sin que tengas que estar presente"
```

**8. La Prueba Social Específica**
Nunca genérica. Siempre con números, nombres o detalles verificables.
```
❌ "Nuestros clientes están muy satisfechos."
✅ "La empresa Textiles Andino redujo su tiempo de respuesta a cotizaciones de 48 horas a 4 horas. En el primer mes, cerraron 2 deals que antes se perdían por demora."
```

**9. La Analogía Poderosa**
Conecta lo nuevo con algo que el lector ya entiende.
```
✅ "Un agente de IA es como contratar a un empleado que trabaja 24/7, nunca se enferma, nunca pide aumento, y mejora solo con el tiempo."
```

**10. El Costo de la Inacción**
Cuantifica lo que cuesta NO actuar.
```
✅ "Si tu proceso actual te hace perder 2 leads por semana, y tu ticket promedio es $500, llevas perdiendo $52,000 al año. No contratar el sistema no es gratis — tiene un costo de $52K."
```

**11. FOMO Legítimo (urgencia real, no artificial)**
```
✅ "Los 3 competidores que vimos esta semana ya están implementando esto. La ventana para diferenciarse se está cerrando."
```

**12. La Garantía como Eliminador de Riesgo**
```
✅ "Si en 30 días no ves un ahorro de mínimo 5 horas/semana en tu equipo, te devolvemos el dinero. Sin preguntas."
```

### Patrones de Cierre (convertir deseo en acción)

**13. El Próximo Paso Obvio**
Un solo CTA claro. Eliminar fricción.
```
✅ "Agenda 20 minutos aquí → [link]. Te mostramos el sistema funcionando con tus datos reales."
```

**14. El Resumen de Valor**
Consolida todo lo que recibe antes del CTA.
```
✅ "En resumen: automatización de onboarding + reporte semanal automático + agente de seguimiento a leads = 12 horas/semana de vuelta a tu equipo, empezando el lunes."
```

**15. El Contrast Pricing**
Compara el costo contra el valor que genera.
```
✅ "La inversión es $X/mes. El costo de seguir como estás es $52,000/año. El ROI es positivo en el mes 1."
```

### Patrones de Humanización (eliminar señales de IA)

**16. La Frase Incompleta Intencional**
El lenguaje natural no siempre es perfecto gramaticalmente. Y eso está bien.

**17. El Paréntesis Personal**
```
✅ "El sistema funciona (y digo funciona porque lo probamos con 3 clientes antes de ofrecerlo)."
```

**18. La Contradicción Honesta**
```
✅ "No es perfecto. En el primer mes hay una curva de ajuste. Pero después de eso, el equipo no quiere volver a lo anterior."
```

**19. El Detalle Innecesario que Humaniza**
```
✅ "Lo construimos en 6 semanas. La semana 4 tuvimos que rehacer todo el módulo de notificaciones. Valió la pena."
```

**20. Preguntas Retóricas en Cascada**
```
✅ "¿Es caro? Depende del benchmark. ¿Comparado con seguir perdiendo 2 leads por semana? No. ¿Comparado con un empleado? Tampoco."
```

### Patrones para Email de Ventas

**21. Asunto: La Curiosidad Específica**
```
❌ "Solución para tu empresa"
✅ "El proceso que [Empresa Similar] usó para reducir su CAC en 40%"
```

**22. Primera Línea: Personalización Real**
```
✅ "Vi que [empresa] acaba de expandirse a Cali. El crecimiento rápido siempre trae el mismo problema: los procesos que funcionaban para 10 clientes se rompen con 50."
```

**23. Cuerpo: Máximo 3 párrafos**
Apertura → Valor específico → CTA. Sin más.

**24. PS: La Segunda Lectura**
El PS es lo segundo que se lee (después del asunto).
```
✅ "PS: Si no es el momento, está bien. Guarda este email para cuando tu equipo esté pasando las 40 horas/semana en tareas que una máquina puede hacer."
```

## Checklist Anti-IA (para humanizar antes de enviar)

```
[ ] ¿Hay frases que empiezan con "En conclusión", "En resumen", "Sin duda"? → Eliminar
[ ] ¿Hay triadas innecesarias? ("rápido, eficiente y profesional") → Romper el patrón
[ ] ¿Hay adjetivos vacíos? ("innovador", "robusto", "de vanguardia") → Reemplazar con datos
[ ] ¿El texto suena como folleto corporativo? → Reescribir en primera persona
[ ] ¿Cada párrafo termina con una conclusión positiva? → Añadir tensión o duda honesta
[ ] ¿El CTA es genérico? ("contáctanos") → Hacerlo específico ("agenda 20 minutos")
```
