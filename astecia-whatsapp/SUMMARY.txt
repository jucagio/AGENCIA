================================================================================
  DECISIONES TÉCNICAS
================================================================================

1. FastAPI + Uvicorn
   → Ultra-rápido para webhooks, async por defecto

2. Claude Haiku (no Sonnet/Opus)
   → Respuesta en 2 segundos, costo 25x menor, suficiente para MAPER

3. Conversación stateful (historial)
   → Juan Camilo puede seguimiento: "¿Y con Cargill?"

4. Async httpx para WhatsApp API
   → No bloquea requests, maneja alta concurrencia

5. Health checks en Railway
   → Auto-restart si falla, monitoring 24/7
