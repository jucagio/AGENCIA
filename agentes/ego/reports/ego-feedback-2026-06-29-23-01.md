## Contexto

- Recomendación: migrar persistencia a **Supabase** (Postgres gratuito), alineado con el stack preferido de la Agencia (ver `CLAUDE.md` → Base de datos: Supabase/Firebase/PostgreSQL).
- Se preguntó al usuario si ya tenía cuenta Supabase → respondió que no, la creará ahora.
- Se entregaron instrucciones paso a paso para: crear cuenta/proyecto en supabase.com, obtener `Project URL` y `anon public key` desde Project Settings → API.
- Se explicitó qué credenciales NO debe compartir (service_role key, contraseña de base de datos) por seguridad — solo la anon key (pública, segura).

## Próximo paso (bloqueado en espera del usuario)

1. Diseñar esquema SQL (tablas: accounts, offers, team_config, stats) — se le entregará el SQL para que él mismo lo corra en el SQL Editor de Supabase (evita pedirle secretos).
