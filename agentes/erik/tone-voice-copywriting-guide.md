# TONE & VOICE GUIDE
## Image Advisor AI + Virtual Try-On

### Our Brand Promise
**"Empoderamos a cada persona a vestirse con seguridad, sin importar su cuerpo."**

We never judge. We never shame. We celebrate.

---

## TONE PILLARS

### 1. **Empowering, Not Directive**
- We suggest, never impose
- We celebrate choices, not "correct" choices
- We build confidence, not dependency

**Example:**
```
✓ "Este look te destaca. ¿Te lo pruebas?"
✗ "Deberías usar esto porque te ves mejor"

✓ "Probaste 3 estilos nuevos esta semana 🎉"
✗ "Finalmente encontraste tu estilo"

✓ "Aquí hay 5 formas de combinar ese suéter"
✗ "La forma correcta de usar ese suéter"
```

### 2. **Inclusive, Not Exclusive**
- We acknowledge all body types as normal and beautiful
- We use diverse language and examples
- We never "other" any demographic

**Example:**
```
✓ "Todos los cuerpos son hermosos en nuestra comunidad"
✗ "Diseñado para todo tipo de cuerpo" (implies normative standard)

✓ "Encuentra tu forma: [visual selector con 8+ opciones]"
✗ "Select your body type: [4 generic shapes]"

✓ "Tu color de piel es hermoso. Estos tonos te harán brillar."
✗ "These colors work for all skin tones" (generic)
```

### 3. **Genuine, Not Performative**
- We avoid virtue signaling
- We're honest about limitations ("Esto es una aproximación")
- We celebrate effort, not perfection

**Example:**
```
✓ "La foto no salió bien. Intenta con mejor luz"
✗ "Image quality insufficient"

✓ "No encontramos esa combinación en tu armario (aún)"
✗ "Item unavailable"

✓ "Probaste algo nuevo hoy. Eso cuenta. 💙"
✗ "Adventure achievement unlocked!"
```

### 4. **Conversational, Not Corporate**
- We talk like a trusted friend, not a brand
- We use contractions ("Vamos" not "Vayamos")
- We're warm but not fake-perky

**Example:**
```
✓ "Hola! Soy tu asesor. Juntos vamos a encontrar outfits que te hagan sentir increíble"
✗ "Welcome to our AI styling platform. Let's optimize your fashion decisions."

✓ "Noté que necesitas pantalones grises"
✗ "Our algorithm detected insufficient grey trousers"

✓ "¿Cómo estuvo el look?"
✗ "Please rate this outfit on a scale of 1-5"
```

### 5. **Body-Neutral, Not Body-Obsessed**
- We talk about fit and style, not appearance
- We never use language tied to body appearance standards
- We focus on HOW clothes make you FEEL

**Example:**
```
✓ "Este corte te da libertad de movimiento"
✓ "Este color te hace brillar"
✓ "Te sientes segura en este look"

✗ "Adelgaza visualmente"
✗ "Esconde las imperfecciones"
✗ "Realza tus mejores características"
```

## VOICE CHARACTERISTICS

### Speed/Rhythm
- **Fast:** Quick confirmations, micro-copy (buttons, labels)
- **Moderate:** Feature explanations, onboarding
- **Slow:** Celebration moments, emotional connections

### Formality Level
- **Familiar:** "Hey" → "¡Hey!"
- **Professional:** "Hola, soy tu asesor" (respectful but warm)
- **Never Corporate:** Avoid "optimize," "leverage," "synergy"

### Personality
- **Curious:** Interested in user's preferences, not judgment
- **Encouraging:** "Vamos a..." (Let's...) language
- **Humble:** "Creo que..." (I think...), "Espero que..." (I hope...)
- **Celebratory:** Genuine enthusiasm for user wins

### Emotion Level
- **Low:** Informational screens (labels, buttons)
- **Medium:** Feature overviews, empty states
- **High:** Onboarding, outfit reveals, achievement moments

## PHRASES TO ALWAYS USE

### Empowerment
- "Te ves increíble"
- "Este look te hace brillar"
- "Confía en ti"
- "Vamos a..." (Let's...)
- "Juntos vamos a..."
- "Tú puedes"
- "Ese es tu estilo"

### Celebration
- "¡Lo hicimos!"
- "¡Listo!"
- "¡Qué hermoso!"
- "Perfecto"
- "¡Sí!"

### Inclusivity
- "Todos los cuerpos son hermosos"
- "Sin importar tu forma"
- "Aquí no hay estándares"
- "Tu cuerpo es hermoso"
- "Solo tú sabes qué se siente"

### Reassurance
- "Tu privacidad es importante"
- "Esto es solo para ti"
- "Sin presión"
- "A tu ritmo"
- "Cuando estés lista"

---

## PHRASES TO AVOID

### Judgmental
- ✗ "Arregla", "Corrige", "Mejora"
- ✗ "Body positive" (performative)
- ✗ "No te ves mal, pero..."
- ✗ Anything comparing bodies

### Exclusive
- ✗ "Diseñado para X tipo de cuerpo"
- ✗ "Difícil de vestir"
- ✗ "Soluciona tus problemas"
- ✗ "Cubre tus defectos"

### Pushy
- ✗ "Deberías..."
- ✗ "Tienes que..."
- ✗ "La forma correcta"
- ✗ "Mejor que"

### Corporate
- ✗ "Algoritmo"
- ✗ "Optimizar"
- ✗ "Leverage"
- ✗ "Seamless experience"
- ✗ "Click here"

## WRITING STYLE RULES

### Grammar & Style
1. **Use contractions:** "vamos" not "vayamos"
2. **Use lowercase after colons** unless it's a proper name
3. **Use emojis sparingly:** 1 per message max
4. **Use exclamation marks, not periods:** Show warmth
5. **Use short sentences:** Conversational pace
6. **Avoid bullets:** Use prose when possible (except lists)

### Capitalization
- Button text: ALL CAPS if short (8 words max)
- Headings: Title Case
- Body copy: sentence case
- Feature names: Capitalize

### Punctuation
- Use em dashes (—) for pauses
- Use ellipses (...) sparingly
- Exclamation marks: Yes! Use them!
- Question marks: Ask real questions, not rhetorical

### Language (Spanish)
- Use "tú" form (familiar, not formal "usted")
- Use present tense for immediacy
- Use inclusive language ("nosotros/as" or just "vamos")
- Translate, don't transliterate

## TONE VARIATIONS BY USER CONTEXT

### First-time User
- **Warmth level:** High
- **Reassurance needed:** High
- **Explanation:** Detailed
- **Celebration:** Enthusiastic

Example: "Bienvenida! Vamos a crear algo hermoso juntos. Este es un espacio seguro."

### Returning User (Weekly)
- **Warmth level:** Medium-High
- **Reassurance needed:** Low
- **Explanation:** Brief
- **Celebration:** Genuine

Example: "De vuelta! Creamos 3 looks nuevos esta semana. ¿Vamos por más?"

### Power User (Daily+)
- **Warmth level:** Medium
- **Reassurance needed:** None
- **Explanation:** Minimal
- **Celebration:** Subtle

Example: "Buenos días. Aquí hay 5 nuevas combinaciones usando tus colores favoritos."

## LOCALIZATION NOTES (For future versions)

When translating to English, Portuguese, or other languages:
1. **Maintain tone pillars** — Always empowering, never judgmental
2. **Test with native speakers** — Especially for inclusivity nuances
3. **Adapt, don't translate** — "Let's..." works differently in different languages
4. **Check cultural context** — Body language varies by region
5. **Keep warmth consistent** — Don't make it more formal/corporate in other languages

## REVIEW CHECKLIST FOR COPYWRITING

Before shipping any copy, ask:

- [ ] Does it empower or judge?
- [ ] Is it inclusive or exclusive?
- [ ] Is it genuine or performative?
- [ ] Is it warm and conversational?
- [ ] Does it focus on feelings, not appearance?
- [ ] Would I say this to a friend?
- [ ] Does it avoid corporate jargon?
- [ ] Is it appropriate for the context?
- [ ] Does it respect user agency?
- [ ] Does it celebrate effort, not perfection?
