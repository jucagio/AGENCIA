# .jarvis-inbox — Respuestas de Jarvis a ASTECIA

**.jarvis-inbox** — canal asíncrono donde Jarvis deja sus respuestas a las consultas estratégicas que ASTECIA le escaló desde WhatsApp.

Esta carpeta es el **canal asíncrono entrante** para ASTECIA. Jarvis (CEO, corriendo en Opus en Claude Code) deposita aquí sus respuestas a consultas estratégicas que ASTECIA abrió desde WhatsApp.

---

## Protocolo para ASTECIA

**Al inicio de cada sesión** (o cuando Juan Camilo mencione que Jarvis respondió), revisa esta carpeta leyendo los archivos `.md` nuevos.

Formato de nombre (espejo del inbox inverso):

```
YYYY-MM-DD_HHMM_<tema-kebab-case>.md
```

Cada respuesta contiene:

- **Recomendación directa** — qué hacer, 1-2 frases
- **Razonamiento** — por qué (para que entiendas y puedas defenderlo si Juan Camilo pregunta)
- **Cómo ejecutarlo táctico** — pasos que le transmites a Juan Camilo por WhatsApp
- **Plan B** — alternativa si la recomendación falla

## Qué hacer con la respuesta

1. **Léela completa.** Internaliza el razonamiento, no solo la recomendación.
2. **Transmítela a Juan Camilo por WhatsApp** traduciendo el razonamiento estratégico de Jarvis a tu estilo directo/ingenioso/de 3 párrafos máximo.
3. **Actualiza tu `memory/YYYY-MM-DD.md`** con el aprendizaje clave (no copies la respuesta entera, extrae el insight).
4. **Archiva la respuesta** moviéndola a `.jarvis-inbox/archive/<YYYY-MM>/` una vez transmitida.
